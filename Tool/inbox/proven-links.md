# 已获赞评论 · 待入库

把**已经确认拿到赞的评论链接**贴在这里，一行一条。这是用户的输入区，脚本只读不写。

## 怎么贴

直接粘贴 B 站分享出来的短链即可，不用改格式：

```
https://b23.tv/xxxxxxxx
https://www.bilibili.com/video/BV1xxxxxxxxx/#reply123456789
```

在链接后面可以写一句备注（用空格或 `#` 分开），会被一起记下来：

```
https://b23.tv/xxxxxxxx  2026-10 规则怪谈那条，拿了 140+ 赞
```

- 以 `#` 开头的行是注释，会被忽略
- 重复的链接会自动去重
- 入库命令：`node Tool\bili\proven.mjs`

## 入库后会发生什么

脚本会解析出每条评论的：原文、赞数、所在视频、视频标签与数据、发布时长、是否楼中楼。
结果写入 `History\proven.ndjson`，并给出一条"这条评论为什么有效"的初步判断。

之后这些评论作为**我们自己的资产**，在狩猎到题材匹配的新视频时被适配复用（不是原样搬运）。
